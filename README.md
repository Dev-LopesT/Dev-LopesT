## Sobre mim

Sou desenvolvedor com foco em **engenharia de aplicações mobile**, trabalhando principalmente com **React Native, TypeScript e Expo**.

Minha atuação envolve desde a construção de interfaces e fluxos de navegação até integração com APIs, autenticação, gerenciamento de estado, arquitetura de aplicações e evolução de produtos digitais.

Além da engenharia de software, tenho experiência com **produto digital, UX/UI, análise de dados, regras de negócio e documentação técnica**, permitindo uma visão mais ampla sobre o produto e não apenas sobre o código.

Atualmente estou aprofundando meus conhecimentos em:

* Arquitetura Mobile
* Performance e otimização
* Design Systems
* Integração Mobile + Back-end
* Testes automatizados
* CI/CD
* Publicação de aplicativos
* Boas práticas e qualidade de código
